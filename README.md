# CNO-V-Seguridad-Informatica

Portafolio digital de evidencias del curso **CNO V – Seguridad Informática**, desarrollado como sitio web estático para documentar actividades, prácticas, reportes y evidencias académicas relacionadas con fundamentos de ciberseguridad, hacking ético, análisis de vulnerabilidades e ingeniería social.

## Descripción

Este repositorio contiene un portafolio académico organizado por parciales.  
Su objetivo es concentrar en un solo sitio las evidencias generadas durante el curso, manteniendo una estructura clara, navegable y profesional.

El proyecto funciona como una bitácora técnica donde se documentan actividades relacionadas con:

- Fundamentos del hacking ético.
- Servicios y mecanismos de seguridad.
- Análisis de metodologías de pentesting.
- Configuración y análisis de herramientas de seguridad.
- Técnicas de explotación en entornos controlados.
- SQL Injection.
- Simulación de phishing.
- Documentación técnica de evidencias.

> Todas las prácticas documentadas tienen fines académicos y se realizan en entornos controlados.
