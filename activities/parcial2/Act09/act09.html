Análisis de Reconocimiento y Enumeración

Uso de herramientas de mapeo de red y análisis de servicios expuestos.

1. Introducción

El reconocimiento y enumeración es una fase crítica en cualquier evaluación de seguridad. En esta actividad, se realizaron escaneos para identificar servicios activos y posibles vectores de ataque iniciales en un entorno controlado.

2. Desarrollo técnico

2.1 Escaneo de red

Se utilizó la herramienta nmap para mapear los puertos abiertos y descubrir los servicios en ejecución en el objetivo (192.168.1.13).

nmap -A 192.168.1.13

2.2 Servicios identificados

  • Puerto 21: FTP
  • Puerto 22: SSH
  • Puerto 80: HTTP
  • Puerto 111/2049: RPC / NFS
  • Puerto 445: Samba

2.3 Análisis de vulnerabilidades potenciales

Una vez obtenidos los puertos y servicios, se procedió a probar la conectividad e interacción con servicios como FTP para identificar configuraciones por defecto o accesos anónimos habilitados:

ftp 192.168.1.13 80

3. Material multimedia

4. Conclusión

La correcta identificación de servicios expuestos permite mapear la superficie de ataque. Un puerto FTP mal configurado o un servicio HTTP desactualizado pueden ser el punto de entrada crítico para comprometer un sistema entero.
