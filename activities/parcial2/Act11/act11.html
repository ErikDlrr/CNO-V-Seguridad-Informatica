Red Team Report: Pentesting de Napping 101

Informe técnico con enfoque ejecutivo y trazabilidad metodológica sobre la explotación de la máquina vulnerable Napping 101.

1. Resumen Ejecutivo

Este reporte detalla las actividades de evaluación de seguridad realizadas sobre el objetivo Napping 101 (IP: 192.168.56.104). El objetivo principal de este ejercicio fue identificar vulnerabilidades críticas, explotarlas de manera controlada y documentar la cadena del ataque.

2. Reconocimiento y Enumeración

2.1 Descubrimiento de Host

La evaluación comenzó con un mapeo de la superficie de ataque mediante nmap para identificar servicios expuestos:

nmap -sS -sV -O -p- 192.168.56.104

2.2 Hallazgos Clave

Puerto Servicio Versión Prioridad
21 FTP vsftpd 3.0.2 Media
22 SSH OpenSSH 7.4 Alta
80 HTTP Apache httpd 2.4.6 Crítica
111 RPC 2-4 Media
445 SMB Samba 3.X-4.X Alta

3. Vector de Ataque y Explotación

El puerto 80 (HTTP) fue identificado como un vector de alta prioridad debido a la exposición de contenido accesible sin autenticación, donde se localizó información crítica (e.g., readme.txt).

4. Cadena del Ataque

5. Conclusión

La evaluación de Napping 101 demuestra cómo servicios comunes mal configurados y la exposición de archivos críticos en servidores web pueden conducir al compromiso total de la infraestructura. La metodología aplicada (PTES) garantiza la trazabilidad de cada fase del pentesting.
