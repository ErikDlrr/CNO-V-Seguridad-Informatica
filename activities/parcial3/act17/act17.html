Evaluación de Vulnerabilidades con CVSS v3.1

Análisis cuantitativo de riesgos y priorización de vulnerabilidades.

1. Introducción

El Common Vulnerability Scoring System (CVSS) proporciona una forma de capturar las características principales de una vulnerabilidad y producir una puntuación numérica que refleja su severidad. En esta actividad se desarrolla la evaluación de una vulnerabilidad web usando el estándar v3.1.

2. Construcción del Vector CVSS

Se identificaron las métricas base según el escenario analizado:

  • Vector de Ataque (AV): Red (N)
  • Complejidad del Ataque (AC): Baja (L)
  • Privilegios Requeridos (PR): Ninguno (N)
  • Interacción del Usuario (UI): Requerida (R)
  • Alcance (S): Cambiado (C)

3. Cálculo de la Puntuación

Utilizando la calculadora oficial de FIRST, se combinaron las métricas de impacto (Confidencialidad, Integridad, Disponibilidad) junto con las métricas de explotabilidad para generar el string vectorial final y el puntaje base.

4. Análisis de Riesgo y Priorización

La asignación de una puntuación CVSS no solo establece un nivel de severidad (Bajo, Medio, Alto, Crítico), sino que permite a los equipos de TI y seguridad priorizar los parches basándose en el riesgo real que representa para la continuidad del negocio.
